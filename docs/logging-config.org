* logging-config

** Load point

Require the module from =init.el= (via the tangle block in =conf.org=)
after its dependencies, unless MAP marks it unloaded:

(require 'logging-config)
#+end_src

** Purpose

Keyword logging (~log/debug~, ~log/info~, ~log/warn~, ~log/error~,
~log/fatal~) via ~warnings.el~ and ~message~.  Writes ~init.log~ on
exit.  View buffers with ~logging-view-mode~.
