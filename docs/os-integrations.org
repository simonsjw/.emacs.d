* OS integrations

This page lists operating-system tools and environment that Emacs on
these machines expects.  =conf.org= keeps the install-oriented table;
this page is the narrative of *where* each piece lives, *how* to install
it, and *how* Emacs finds it.  Keep the two in sync when a module gains
or drops an OS dependency.

Australian English in prose.  Sentences end with two spaces when more
than one appears in a paragraph.

** Identity, paths, env

| ~USER_EMACS_DIRECTORY~ | Config root | shell profile | ~export USER_EMACS_DIRECTORY=/home/simon/.emacs.d~ | =early-init.el= ~setq user-emacs-directory~ | =early-init.el= |
| ~ENV_FILE~ | Extra env dump loaded at startup | e.g. =/home/simon/Me/secrets/serviceEnv.txt= | Create the file; ~export ENV_FILE=…~ | =init.el= ~load-environment-variables-from-file~ | =init.el= tangle |

| =etc/$MY_NAME/= | Machine-local *configuration* (=custom.el=, eln-cache, lang-servers, dape adapters) | under this repo | created by =path-support.el= | ~no-littering-etc-directory~ | =path-support.el= |
| ~BIB_HOME~ | Default bibliography | e.g. LaTeX templates =refs.bib= | export in profile | ~citar-bibliography~ via ~(getenv "BIB_HOME")~ | =writing-config.el= |
| ~REPO_LIST~ | CSV of git repos | e.g. dotfiles =repoList.csv= | export | ~my/REPO_LIST~ in =init.el= | =init.el= |
| ~PROJECT_PATHS~ | Project search roots | profile + ~$ENV_FILE~ | Grammar: *comma-separated* ~dir:depth~ entries. Rename ~PROJECTILE_PATHS~ to ~PROJECT_PATHS~ in =~/.bashrc~ and ~$ENV_FILE~ out of band (do not commit those files).  Lisp does not read this variable today (documented for ~project.el~ / project-view follow-up). | document for ~project.el~ / project-view | =conf.org=, =project-support.el= |
| ~PATH~ | Binaries | login shell | wrapper sources bashrc | ~exec-path-from-shell~ / ~my-env-tools/exec-path-from-shell-report~ | =system-tools.el=, =defaults-config.el= |
| SSH agent | ~SSH_AUTH_SOCK~ | gnome-keyring or gcr | wrapper re-asserts after bashrc | Magit is not used; ~vc~ / Tramp use the env | wrapper + Tramp |

*** ImageMagick PDF policy

Security policy file: =/etc/ImageMagick-6/policy.xml= or
=/etc/ImageMagick/policy.xml=.

Change:

#+begin_src xml
  <policy domain="coder" rights="none" pattern="PDF" />
#+end_src

to:

#+begin_src xml
  <policy domain="coder" rights="read|write" pattern="PDF" />
#+end_src

Needed so Org/LaTeX preview can produce PDFs.
