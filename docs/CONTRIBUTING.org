* Contributing documentation

The documentation here is written in Org mode.  The primary Info
source is =emacs-config.org=.  Each first-party module has its own Org
page =docs/<feature>.org=, included from that master file.

=my-docs.el= provides the export helpers.  To keep the Info build
reproducible and independent of a personal Emacs session, export with
one of the two methods below.

Do not run =M-x org-texinfo-export-to-info RET= or =org-export-dispatch=
directly for the published manual.  Those paths introduce noisy diffs
from session-local settings.

** Interactively from Emacs

Requirements:
- ~emacs~ on ~$PATH~

Load the helper from the =docs/= directory:

#+begin_src emacs-lisp
  (load (expand-file-name "my-docs.el"))
#+end_src

Then run =M-x my-docs-export RET=.

If you develop inside this checkout, set
~my-docs-export-use-user-emacs-directory~ to =t= so the exporter finds
the =docs/= tree under ~user-emacs-directory~.

** Using ~make~

Requirements:
- ~emacs~ on ~$PATH~
- ~make~ on ~$PATH~

From the =docs/= directory:

#+begin_src shell
  make docs
#+end_src

Running =make docs= builds =emacs-config.info= when the Org sources are
newer than the Info file.

* Documenting a module

Add an Org file named for the feature, for example
=docs/defaults-config.org=.  Feature name equals the ~provide~ symbol
and the filename stem.  Keep =docs/MAP.org= in sync in the same change.

When the page is ready for the Info manual, include it from
=emacs-config.org=:

#+begin_example
  ,#+include: defaults-config.org
#+end_example

Export with =make docs= (or =M-x my-docs-export RET=) and open a PR.

* Guidelines

- Provide examples.
- Use correct grammar and Australian English spelling in prose.
- Spellcheck your work.
- Use consistent Org markup:
  - use === for ::
    - file paths, e.g. =init.el=
    - buffer names, e.g. =*Messages*=
    - values (except numbers, which stay plain), e.g. =nil=
    - keystrokes or keybindings, e.g. =C-n=
    - text (to be) entered into the minibuffer (unless it is a complete
      command name), e.g. =buf=
    - info nodes, e.g. =(emacs)Just Spaces=
  - use =~= for ::
    - module names, e.g. ~defaults-config~
    - variable names, incl. external ones, e.g. ~load-prefer-newer~, ~$PATH~
    - function names, e.g. ~car~
    - command names, incl. external ones, e.g. ~find-file~, ~make~
    - package names, incl. ones that are shaped like a file name, e.g. ~denote~,
      ~package.el~
- Preview the Info document in Emacs to confirm the formatting.
- Use =@@texinfo:@code{}@@= or =@@texinfo:@samp{}@@= where Org markup
  does not translate cleanly to Texinfo.
- End sentences with two spaces in new Org prose that will be tangled
  or checked alongside Elisp style.
