* lang-python-menus

** Load point

Required by ~lang-python~, not from =init.el= directly:

#+begin_src emacs-lisp
(require 'lang-python-menus)
#+end_src

** Purpose

Piece of ~lang-python~: Tools menu entries and the Python context menu.
~my-lang-python/menus-setup~ installs menus, remaining keys, and
~context-menu-functions~ from the loader hook.

** Depends

- ~path-support~
- ~logging-config~

** Provides

- Feature ~lang-python-menus~ from =custom-modules/prog-mode/lang-python-menus.el=.

** Keymaps

- none on a dedicated keymap file; binds on ~python-ts-mode-map~ from ~menus-setup~

** OS dependencies

none
