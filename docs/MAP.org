#+title: .emacs.d module map

This file is the inventory for humans and coding agents.
Feature equals the ~provide~ symbol and the filename stem.
Keep one row per first-party feature.  Update it in the same change
as the Lisp.

Phases: ~early~, ~bootstrap~, ~defaults~, ~ui~, ~ide~, ~lang~, ~tools~,
~keymaps~, ~startup~.  Depends lists features that must already be loaded.
Keymaps names the =custom-modules/keymaps/= file when bindings live there.
Docs paths are the intended =docs/<feature>.org= pages (stubs come in a
later PR).
