* lang-lisp

** Load point

Require the module from =init.el= (via the tangle block in =conf.org=)
after its dependencies, unless MAP marks it unloaded:

#+begin_src emacs-lisp
(require 'lang-lisp)
#+end_src

** Purpose

(CIDER / clj-refactor), Scheme and Racket (Geiser).  Diagnostics use
Flymake, not Flycheck.
