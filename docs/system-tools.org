* system-tools

** Load point

Require the module from =init.el= (via the tangle block in =conf.org=)
after its dependencies:

#+begin_src emacs-lisp
(require 'system-tools)
#+end_src

Do not require the piece files from =init.el=; the loader pulls them in.

** Purpose

Loader and ~provide~ of shared system helpers.  Keeps dictionary and
SSH commands.  Requires the piece files: env, disk, buffer, and frame.

Directory creation is ~my-on-disk-tools/ensure-directory-exists~ in
=path-support.el= (~"Creating directory: %s"~).  Do not reintroduce a
second copy.

** Depends

- ~path-support~
- ~logging-config~

** Provides

- Feature ~system-tools~ from =custom-modules/system-tools/system-tools.el=.

** Keymaps

- none

** OS dependencies

| Tool | Install hint | Used for |
|------+--------------+----------|

** Variables

none on the loader itself; see the piece files.
