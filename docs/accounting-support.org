* accounting-support

** Load point

Require the module from =init.el= (via the tangle block in =conf.org=)
after its dependencies, unless MAP marks it unloaded:

#+begin_src emacs-lisp
(require 'accounting-support)
#+end_src

** Purpose

hledger-mode reports and hledger-web launcher.  Completion uses CAPF
with Corfu when ~hledger-completion-at-point~ is available (not
company-mode).

** Depends

Features that must already be loaded (match the Commentary =Map:=
block and the row in =docs/MAP.org=):

- ~logging-config~

** Provides

- Feature ~accounting-support~ from =custom-modules/accounting-support.el=.

** Keymaps

- none (global ~C-c a~ report keys live in this module)

** OS dependencies

List binaries or services the module expects.  Keep this in sync with
