* path-support

** Load point

Loaded from =early-init.el= (tangled from =conf.org=) before
~logging-config~:

#+begin_src emacs-lisp
(load-file (expand-file-name "custom-modules/path-support.el"
                             user-emacs-directory))
#+end_src

** Purpose

Single source of ~my-paths/~ constants, ~no-littering-var-directory~ /
~no-littering-etc-directory~, and load-path roots.  Form-feed (~^L~)
characters in the Lisp file are historical; do not add more.

** Depends

- none (early; logging is not available yet)

** Provides

- Feature ~path-support~ from =custom-modules/path-support.el=.

** Variables

- ~envvar/SYSTEM_NAME~ — from ~$MY_NAME~, default ~INFODYNAMICS~
- ~no-littering-var-directory~ — =var/$MY_NAME/=
- ~no-littering-etc-directory~ — =etc/$MY_NAME/=
- ~my-paths/~ constants — every first-party path; add new ones in the
  dedicated path-constants PR, not as drive-by edits

** Commands and keys
